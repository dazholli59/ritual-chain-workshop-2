# Activity Counter

I added this mostly as a small way to inspect market
activity while learning the workshop.

The helper counts three simple activity types:

- CREATE
- BET
- RESOLVE

It can also count activity for one market.

I kept this outside the contract because it is only an
inspection helper.

The main thing I wanted to understand was how several
events could be grouped around the same market ID.

This is not intended to be a full indexer.
It is just a small utility for the workshop.
